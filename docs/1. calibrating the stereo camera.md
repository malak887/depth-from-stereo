
**Calibrating the stereo camera**

Purpose
- Extract accurate intrinsic and extrinsic camera parameters required for rectification and depth estimation.

Overview
- We use a standard planar-pattern method (Zhang's method) to estimate camera intrinsics (focal length, principal point, skew, distortion coefficients) and extrinsics (rotation and translation between the cameras). Accurate calibration reduces image distortion and is essential for reliable disparity and depth results.

Requirements
- A printed checkerboard or other planar calibration target.
- A set of stereo image pairs stored in `frames/` (or captured with `streaming.py`).
- The calibration outputs will be stored in `camera_parameters/`.

Capture guidelines (best practices)
- Use 15–40 image pairs covering a wide range of orientations and distances.
- Fill the frame with the checkerboard at different positions and angles; include rotations and tilts.
- Avoid motion blur and strong reflections; use consistent, even lighting.
- Make sure both cameras see the entire checkerboard in each pair.

Calibration steps (high level)
1. Capture a set of synchronized stereo image pairs with the checkerboard visible in both images.
2. Detect checkerboard corners in each image and refine corner positions (subpixel accuracy).
3. Calibrate each camera individually to estimate intrinsics and distortion coefficients.
4. Run stereo calibration to estimate the rotation and translation between cameras and to refine intrinsics.
5. Compute rectification transforms and the disparity-to-depth reprojection matrix (Q matrix).
6. Save all parameters to `camera_parameters/` for later use.

Evaluation
- Report the mean reprojection error (lower is better). Typical acceptable values are < 0.5 pixels for high-quality images; up to 1.0 pixel can be acceptable depending on capture conditions.
- Visually verify rectification by checking that corresponding epipolar lines are horizontal and that features align vertically between rectified left/right images.

Tools
- OpenCV: flexible and scriptable; used in this project for detection, calibration, and rectification.
- MATLAB Stereo Camera Calibrator: GUI-based and sometimes gives lower reprojection errors for difficult setups.

Tips and troubleshooting
- If reprojection error is high: collect more diverse images, improve lighting, ensure accurate corner detection, or use a larger checkerboard.
- If one camera's intrinsics look wrong: calibrate that camera separately with many single-camera images.
- For robust corner detection, try different preprocessing (resize, equalize histogram) before running the detector.

References
- Zhang, Z. "A flexible new technique for camera calibration." IEEE Transactions on Pattern Analysis and Machine Intelligence, 2000.
- MATLAB Stereo Camera Calibrator: https://www.mathworks.com/help/vision/ug/using-the-stereo-camera-calibrator-app.html

Saved parameters and next steps
- After calibration, ensure the produced files in `camera_parameters/` are loaded by `read_calib.py` and used by `disparity.py` and `depth.py` for rectification and depth estimation.
