
What is a disparity map?
- A disparity map encodes the horizontal pixel offset (disparity) between corresponding points in a rectified stereo pair. Larger disparities correspond to closer objects; smaller disparities correspond to objects that are farther away.

Purpose
- Disparity is the intermediate result used to compute depth. After obtaining disparity and the reprojection matrix `Q`, you can convert disparity values to 3D coordinates or a depth map.

Algorithm used
- This project uses OpenCV's Semi-Global Block Matching (`cv2.StereoSGBM_create`) to compute dense disparity maps. For visualization quality, a weighted least squares (WLS) filter is applied to reduce noise and improve edges (available in `cv2.ximgproc`).

Important parameters to tune
- `minDisparity`: minimum possible disparity value (often 0).
- `numDisparities`: number of disparities to search (multiple of 16). Larger values can detect nearer objects but are slower.
- `blockSize`: SAD window size (odd number). Larger windows are more robust to noise but lose detail.
- `P1`, `P2`: penalty terms controlling smoothness (typically proportional to `blockSize`).
- `uniquenessRatio`, `speckleWindowSize`, `speckleRange`: filters to remove spurious matches.

Visualization
- Disparity is often stored as a 16-bit signed image (disparity*16). Normalize it for display using `cv2.normalize` or convert to an 8-bit colormap.

Minimal example (compute + visualize):

```python
import cv2
from cv2 import ximgproc

# rectified grayscale images: left_gray, right_gray
stereo = cv2.StereoSGBM_create(minDisparity=0, numDisparities=256, blockSize=7,
							   P1=8*3*7**2, P2=32*3*7**2,
							   uniquenessRatio=10, speckleWindowSize=100, speckleRange=32)
disp = stereo.compute(left_gray, right_gray).astype(np.float32) / 16.0

# Optional WLS filter
right_matcher = ximgproc.createRightMatcher(stereo)
wls_filter = ximgproc.createDisparityWLSFilter(stereo)
wls_filter.setLambda(8000)
wls_filter.setSigmaColor(1.5)
filtered = wls_filter.filter(disp, left_gray, None, right_matcher.compute(right_gray, left_gray).astype(np.float32)/16.0)

# Normalize for display
disp_vis = cv2.normalize(filtered, None, alpha=0, beta=255, norm_type=cv2.NORM_MINMAX)
disp_vis = np.uint8(disp_vis)
disp_color = cv2.applyColorMap(disp_vis, cv2.COLORMAP_JET)
cv2.imshow('Disparity', disp_color)
cv2.waitKey(0)
```

Converting disparity to depth
- Given the disparity `d` and the reprojection matrix `Q`, convert image points to 3D coordinates or compute depth (Z) using `cv2.reprojectImageTo3D(disp, Q)`.

Troubleshooting
- If disparity is noisy: increase `blockSize`, tune `P1/P2`, or apply the WLS filter.
- If large flat areas have no disparity: increase `numDisparities` or improve image texture (lighting).
