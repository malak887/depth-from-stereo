Image rectification reprojects left/right images so their epipolar lines are aligned (typically horizontally). After rectification, matching points lie on the same scanline, which greatly simplifies stereo matching and improves depth estimation.

When to use
- Always rectify stereo pairs before computing disparity or performing point triangulation.

How it works (overview)
- Use the camera intrinsics and the stereo extrinsics (rotation/translation) to compute rectification transforms for both cameras.
- Apply those transforms and undistortion to each image so corresponding rows represent the same epipolar lines.

OpenCV workflow (typical)
1. Load camera intrinsics and stereo extrinsics from calibration outputs (see `camera_parameters/`).
2. Call `cv.stereoRectify()` to compute rectification transforms `R1, R2` and projection matrices `P1, P2`, plus the disparity-to-depth matrix `Q`.
3. Use `cv.initUndistortRectifyMap()` for each camera to create remap matrices.
4. Apply `cv.remap()` to produce the rectified images.

Minimal example (OpenCV, Python):

```python
import cv2
import numpy as np

# assume camera matrices K1,K2, dist1,dist2, R, T are loaded
R1, R2, P1, P2, Q, _, _ = cv2.stereoRectify(K1, dist1, K2, dist2, imageSize, R, T)
map1x, map1y = cv2.initUndistortRectifyMap(K1, dist1, R1, P1, imageSize, cv2.CV_32FC1)
map2x, map2y = cv2.initUndistortRectifyMap(K2, dist2, R2, P2, imageSize, cv2.CV_32FC1)
rect1 = cv2.remap(img1, map1x, map1y, interpolation=cv2.INTER_LINEAR)
rect2 = cv2.remap(img2, map2x, map2y, interpolation=cv2.INTER_LINEAR)
```

Verification
- Visual check: draw horizontal lines (every N rows) on both rectified images — corresponding features should lie on the same horizontal line.
- Epipolar check: feature correspondences should have the same y-coordinate after rectification.

Output
- Save rectified images to `output/rectified_left.png` and `output/rectified_right.png` for downstream disparity and depth processing.

Troubleshooting
- If rectified images show severe warping, re-check intrinsics and extrinsics and ensure `imageSize` matches the images used for calibration.
- If features don't align vertically, confirm that the correct `R` and `T` (stereo extrinsics) are used.
