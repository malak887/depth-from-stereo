
Purpose
- Convert pixel disparities into metric depth (distance from camera to scene points).

Basic formula

$$
Z = \frac{f\,B}{d}
$$

where:
- $Z$ is depth (same units as baseline $B$)
- $f$ is the focal length in pixels (use the focal length from rectified projection matrix `P1[0,0]` / `P2[0,0]`)
- $B$ is the baseline (distance between camera centers)
- $d$ is the disparity in pixels

Notes on components
- **Focal length:** After rectification intrinsics may be scaled; read the focal length from the rectified projection matrix returned by `cv2.stereoRectify` (usually `P1[0,0]`).
- **Baseline:** Measure the physical distance between the camera centers in meters (or millimeters). Depth will be in the same units.
- **Disparity:** Can come from a dense stereo matcher (SGBM) or from a direct feature-match for a specific point. For a single-point, matching with sub-pixel refinement improves accuracy.

Practical per-point depth (feature-matching) steps
1. Rectify the stereo pair so corresponding epipolar lines are horizontal.
2. Select a point `(x, y)` in the left rectified image.
3. Extract a small window around `(x, y)` and search horizontally in the right image for the best match (SSD/NCC). Use sub-pixel refinement (e.g., parabolic fit) for better precision.
4. Compute disparity `d = x_left - x_right` and depth using the formula above.

Dense disparity → depth
- For full-image depth, compute a dense disparity map (e.g., SGBM), optionally filter it (WLS), then convert to 3D with `cv2.reprojectImageTo3D()` using the `Q` matrix from `stereoRectify`.

Accuracy tips
- Use sub-pixel disparity estimation for point measurements.
- Average disparity over a small neighborhood (e.g., 3x3 or 5x5) to reduce noise.
- Apply median or bilateral filtering to dense disparity maps before reprojecting.
- Ensure `numDisparities` covers expected scene distances; too small a range clips near objects.

Example (point depth using disparity value):

```python
import numpy as np

# focal_px from rectified P matrix, baseline_m in meters, disparity_px from matcher
def depth_from_disparity(focal_px, baseline_m, disparity_px):
  if disparity_px <= 0:
    return np.nan
  return (focal_px * baseline_m) / disparity_px

# example
z = depth_from_disparity(focal_px=1200.0, baseline_m=0.12, disparity_px=24.0)
print(f"Depth: {z:.3f} m")
```

Troubleshooting
- If depths are wildly incorrect: verify units (baseline in meters vs mm), confirm focal length is from rectified projection matrix, and check disparity sign/scale (some matchers output disparity multiplied by a factor, e.g., 16).
