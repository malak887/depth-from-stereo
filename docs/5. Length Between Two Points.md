
Purpose
- Compute the Euclidean distance between two selected image points after projecting them to 3D.

Overview
- Convert pixel coordinates (+ disparity/depth) to 3D coordinates, then compute the distance:

$$
d = \sqrt{(X_2-X_1)^2 + (Y_2-Y_1)^2 + (Z_2-Z_1)^2}
$$

Method A — Using `cv2.reprojectImageTo3D`
- Input: dense disparity map and `Q` matrix from `cv2.stereoRectify`.
- `cv2.reprojectImageTo3D(disp, Q)` returns a 3D point for every pixel. Use indexing to pick the two points and compute their Euclidean distance with `np.linalg.norm()`.

Example:

```python
import cv2
import numpy as np

# disp: disparity (float32), Q: reprojection matrix
points_3d = cv2.reprojectImageTo3D(disp, Q)
p1 = points_3d[y1, x1]
p2 = points_3d[y2, x2]
dist = np.linalg.norm(p1 - p2)
```

Method B — Manual projection from depth (feature-matching)
- If you compute a more accurate per-point depth `z` using feature matching, convert pixel `(x,y)` to 3D:

$$
X = (x - c_x) \frac{Z}{f_x},\quad Y = (y - c_y) \frac{Z}{f_y}
$$

Example:

```python
def pixel_to_3d(x, y, z, cx, cy, fx, fy):
    X = (x - cx) * z / fx
    Y = (y - cy) * z / fy
    return np.array([X, Y, z])

p1 = pixel_to_3d(x1, y1, z1, cx, cy, fx, fy)
p2 = pixel_to_3d(x2, y2, z2, cx, cy, fx, fy)
dist = np.linalg.norm(p1 - p2)
```

Accuracy tips
- Prefer method B for pointwise measurements if you can obtain reliable sub-pixel disparity or a feature-matching depth estimate.
- When using dense disparity (method A):
  - Apply WLS or median filtering to the disparity map before reprojection.
  - Ignore or mask invalid disparities (NaN or very large/small values).
  - Average 3D coordinates over a small window around each selected pixel to reduce noise.

Common pitfalls
- Unit mismatch: ensure baseline and focal lengths use consistent units so the resulting distances are in the expected units.
- Disparity scale: some matchers output disparity scaled by a factor (e.g., 16). Divide by that factor before reprojecting.
